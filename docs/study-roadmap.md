# Study Roadmap

1. Run the query and comparison commands.
2. Read the normal scorer and binary-selection document.
3. Change a relevance or similarity value and rerun tests.
4. Use the circuit debugger to inspect amplitudes and probabilities.
5. Read the QUBO and QAOA documents.
6. Add a selector implementing the common interface.
7. Add parameter logging and a true PennyLane simulator backend.
8. Only then explore noise and real hardware.

Exercises: construct a three-page hand-scored problem; predict the brute-force optimum; verify its QUBO energy; explain why Top-K can choose redundant pages; and record a negative result where classical selection wins.
