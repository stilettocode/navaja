# Quantum Computing for Programmers

A quantum circuit is a transformation pipeline over a state. A classical program stores one current value; a simulator stores amplitudes associated with possible bitstrings. Measurement turns that state into one sampled classical bitstring, so the many amplitudes cannot simply be read as many answers.

A quantum computer is not a massively parallel CPU. Useful algorithms depend on gate operations and interference arranging measurement probabilities. Superposition alone is not a speedup.
